**Decal notation** is the compact coordinate shorthand used in EO to specify a transformation's position on the Object axis (Ω; also called the Time axis). The notation affixes one of three symbols — **−**, **+**, or ***** — to an operator name, pinning the third coordinate that the operator name alone leaves unresolved.

The term "decal" is informal: a small mark pressed onto a surface, like a sticker on a model airplane. The operator carries two coordinates (Identity ⤫ Space). The decal adds the third.

## The Three Symbols

Each symbol corresponds to one of EO's three coordinate values, which recur on all three axes of the capacity ground:

The emergent value on the Object axis is denoted τ (tau), the constant of recurrence. Pattern is the Object-axis position that only exists across time — it cannot be observed in a single moment.

## How It Works

The nine EO operators are compressions of two axes: α (Mode / Identity) and η (Domain / Space). Each operator name already encodes a fixed position on these two dimensions. DEF, for example, sits at Relating ⤫ Significance. CON sits at Relating ⤫ Structure.

What the operator name does *not* specify is the third axis — Object (Time). The same operator, aimed at different kinds of targets, produces different transformations. Decal notation resolves this ambiguity.

**EVA−** — Evaluation aimed at a Ground condition. Assessing an ambient context. *Doubt, wonder, pretend, tolerate.*

**EVA+** — Evaluation aimed at a Figure. Judging a specific particular against a standard. *Deny, censor, suppress, hide.*

**EVA*** — Evaluation aimed at a Pattern. Judging a regularity against criteria. *Conflict, contradict, disagree.*

Same operator. Three categorically different experiences. The decal is the difference.

## The Unmarked Operator

An operator written without a decal — simply "DEF" or "CON" — is not shorthand for one of the three positions. It indicates that the Object axis is **unresolved**: the operation has been identified on the Identity ⤫ Space face, but the targeting dimension has not yet been specified.

This is a legitimate analytical state. In diagnostic use, identifying the operator often precedes identifying what it is aimed at. The unmarked form names the operation; the decal pins the target.

## Relationship to the Three Faces

The 27-cell cube can be projected onto three 2D faces, each produced by collapsing one axis:

**Face 1 — The Act** (Mode ⤫ Domain): The nine operators. This is what the operator name encodes. The decal is absent — Object is collapsed.

**Face 2 — The Stance** (Mode ⤫ Object): How the transformation lands. This is what the decal specifies when combined with the Mode component of the operator. EVA+ has Mode = Differentiating and Object = Figure, placing it at "Dissecting" on the Stance face.

**Face 3 — The Site** (Domain ⤫ Object): Where in reality the target sits. This is what the decal specifies when combined with the Domain component. EVA+ has Domain = Significance and Object = Figure, placing it at "Lens" on the Site face.

The decal, combined with the operator, generates all three face readings simultaneously.

## Relationship to Composition

The 81 Names document reveals that the three decal positions correspond to three compositional forms:

**−** (Reversal)

Ground-operator applied to the operator's output

Returns to conditions; undoes or inverts

|  |
|  |

**+** (Forward)

Operator applied to its target

The operation as such; the canonical act

***** (Self-application)

Operator applied to itself

The operator encountering its own pattern

This means the decal positions are not merely labels for a targeting dimension. They are the Figure/Pattern/Ground trichotomy applied to the operator *itself* — a further instance of the fractal self-similarity that structures the entire framework. The − position is the operator's ground (its reversal conditions). The + position is the operator's figure (its forward action). The * position is the operator's pattern (what it does when it meets itself).

Nesting handles the compositional logic. The decal names the result.

## Usage

Decal notation appears in practitioner contexts — case analysis, diagnostic logs, teaching, and informal theoretical discussion. It is designed for speed: three characters (operator code + decal) specify a full form without requiring the bracket notation [0, √2, √2] or the full verbal description "Evaluation aimed at a specific entity."

In formal or algebraic contexts, the Greek notation with explicit coordinate triples is preferred: ψ at [0, √2, √2].

Both notations refer to the same 27 positions. The decal is for reading. The coordinates are for calculating.
